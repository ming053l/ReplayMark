\paragraph{Schedule preservation.}
Shibboleth does not serialize the
DLM. In our control, the left-to-right schedule needed by KGW raises PPL by
$1.17\times$ relative to block decoding and produces a high duplicate-bigram rate before
watermarking. dgMARK uses order sensitivity as its channel, whereas Shibboleth keeps the
reference order fixed and acts after a live probability row is available. Constructing the
response bank adds $28\%$ generation evaluations.

\paragraph{Model-bound verification.}
A token-only detector tests whether token identities correlate with a key. Shibboleth tests a
different question: whether the emitted tokens exhibit keyed responses when a specified
model reconstructs them under counterfactual context views. The resulting statistic is bound
jointly to text, context, and checkpoint. Verification therefore assumes access to the specified
checkpoint; a different checkpoint need not reproduce the responses.

\paragraph{Adaptive carrier discovery.}
The admission rule chooses carriers and probe pairs from the completed prefix and model probabilities;
the number and identity of trials are consequently data dependent. Nevertheless, after
conditioning on those choices, the orientation bits remain independent fair coins and the
binomial tail is exact after conditioning. Without bigram deduplication, the measured KGW
control has $37\%$ FPR, showing that dependence and trial definition affect calibration.

\paragraph{Integration and verification cost.}
Shibboleth preserves a deployed DLM's block and confidence schedule, requires no training, and
implements retries using the stored probability row. Verification requires the specified
checkpoint and 144 masked evaluations. KGW and dgMARK use zero-inference detectors, have higher
local TPR on LLaDA, and use token-local statistics. Wall-clock latency, memory,
cross-hardware reproducibility, and multi-checkpoint behavior were not measured.

\paragraph{Limitations.}
Results cover two checkpoints, one prompt corpus, cohorts of twenty to fifty documents,
automatic perplexity measurements, and a 50-problem GSM8K evaluation. Human evaluation,
larger cohorts, scalable verification, adaptive attacks, and content-anchored synchronization
were not evaluated.
