\section{Shibboleth: Watermarking by Model Response}
\label{sec:method}

\subsection{Masked Decoding}
\label{sec:prelim}

A masked DLM does not have a unique ``next token.'' It sees a sequence containing masks and
returns a distribution at every unresolved position. Let $x$ be the prompt,
$y=(y_1,\ldots,y_N)$ the continuation, and $I$ the positions already revealed. At any masked
position $i\notin I$, the model provides $p_\theta(y_i\mid y_I,x)$. One forward pass over the
full sequence provides these distributions for every unresolved position; we count this as one
full-sequence model call.

We study the blockwise schedule used by LLaDA~\citep{arriola2025blockdiffusion,
nie2025llada}. Blocks finish from left to right, while a confidence rule decides which masks
inside the active block commit at each step. We write $B_b$ for the active block and $F_b$ for
the completed prefix before it. Shibboleth keeps both the block order and this confidence rule.

\subsection{Problem Setup}
\label{sec:setup}

The goal is to distinguish text generated with a secret document key from text generated
independently of that key, at a false-positive rate fixed in advance. The watermark may change
which token is sampled, but it should not replace the model's decoder or its schedule.

\paragraph{What the two parties retain.}
The embedder has the model, prompt, secret key $K$, and target bits. The verifier later has the
completed sequence, the same checkpoint, $K$, and public parameters---but no generation trace,
stored logits, random seed, or record of rejected samples. A nonce derives a fresh document key
$K_d=\mathrm{HMAC}(K,\mathrm{nonce}_d)$~\citep{bellare1996hmac}. Separate hash domains use
$K_d$ for probe construction, carrier assignment, and the requested response directions.

\paragraph{Guarantee and scope.}
For any text produced independently of $K_d$, including output from another sampler, a detector
run at level $\alpha$ fires with probability at most $\alpha$. This guarantee is finite-sample
and permits the method to choose a data-dependent number of carriers. It does not promise
detection after editing, key disclosure, adaptive detector queries
~\citep{jovanovic2024stealing}, or replay with a numerically different checkpoint.

\paragraph{Why write during generation?}
A tempting alternative is to watermark only after the text is complete. Across 36 post-hoc
substitution settings, however, the
median selected position has only one candidate within a 3-nat likelihood budget, and the best
setting below a $1.35\times$ PPL budget reaches $0.10$ TPR at $1\%$ FPR. Shibboleth therefore
writes while the model's live distribution is available.
\label{sec:posthoc}

The design follows three requirements:
\begin{enumerate}[leftmargin=1.6em,itemsep=1pt,topsep=2pt,label=\arabic*.]
\item \textbf{Replayability.} From the completed sequence, the verifier must reconstruct the
same masked context that the embedder used.
\item \textbf{Blind selection.} Carrier positions must be fixed before the key reveals which
response direction counts as a match.
\item \textbf{Schedule preservation.} Blocks and within-block commit order must remain those of
the reference decoder.
\end{enumerate}

Replayability makes a generation-time response measurable later; blind selection keeps
data-dependent carrier discovery from changing the stated false-positive rate. The next three
subsections implement these requirements.
