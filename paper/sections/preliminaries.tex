\section{Background and Problem Setup}
\label{sec:prelim}

\paragraph{Blockwise masked diffusion.}
Let $x$ be a prompt and $y=(y_1,\ldots,y_N)$ the generated continuation. We study the
semi-autoregressive schedule used by LLaDA: $y$ is partitioned into contiguous blocks,
blocks are completed from left to right, and diffusion resolves masks within the active
block~\citep{arriola2025blockdiffusion,nie2025llada}. When block $B_b$ is active, the
prompt and earlier blocks are fixed while $B_b$ and all later blocks remain masked. A
masked DLM returns a categorical distribution for every unresolved position in one
sequence evaluation; the sampler commits the most confident positions according to the
reference schedule.

\paragraph{Verification setting.}
The embedder receives the model, prompt, secret key $K$, and message. The verifier later
receives only the completed token sequence, the same model, $K$, and public decoding
parameters. It does not receive logits, random seeds, or the order in which tokens were
committed. Each document uses a nonce-derived key
$K_d=\mathrm{HMAC}(K,\mathrm{nonce}_d)$. The null hypothesis covers any text produced
independently of $K_d$; it does not require a particular natural-text distribution.

We evaluate three properties. \emph{Validity} requires false-positive control under the
null. \emph{Power} is reported as true-positive rate (TPR) at a fixed false-positive rate
(FPR). \emph{Cost} includes both changes in text quality and the model evaluations required
at generation and verification time. Because ReTrace changes the sampling distribution,
quality is always compared with a non-watermarked control using the same base schedule and
sampling temperature.
