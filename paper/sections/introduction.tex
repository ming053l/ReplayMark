\section{Introduction}
\label{sec:intro}

Language-model watermarks usually encode a secret pattern in the generated sequence.
Red--green methods bias the probability of keyed token subsets
\citep{kirchenbauer2023watermark}; sampling-based methods correlate token choices with a
pseudorandom sequence~\citep{kuditipudi2024distortionfree}; and recent methods for
diffusion language models (DLMs) use denoising order or unresolved context as additional
embedding channels~\citep{hong2026dgmark}. Their implementations differ, but their
detectors can evaluate the watermark from token identities and a key without running the
generator.

This paper asks whether model inference itself can provide a useful verification signal.
A masked DLM is trained to predict missing tokens from arbitrary visible context. The same
operation can therefore be applied to a completed text: hide selected context, run the
model, and measure how its predictions change. The central question is whether that
change can be keyed, reproduced by a verifier, and steered during generation.

ReTrace implements this idea with paired context ablations. For a generated token $y_i$,
the verifier masks two different subsets of the already completed context and computes
\begin{equation}
g_i(y_i) = \log p_\theta\!\left(y_i \mid C^1_i(y)\right)
          - \log p_\theta\!\left(y_i \mid C^0_i(y)\right).
\label{eq:contrast}
\end{equation}
The key supplies an independent orientation bit that determines which sign counts as a
match. ReTrace counts matches only at positions where the two signs both have appreciable
probability. For a text independent of the key, the orientation bits are fair coins, so
the conditional null is exactly $\mathrm{Binomial}(n,\tfrac12)$. This guarantee does not
depend on a calibration corpus or a Gaussian approximation.

Embedding uses the same observable. During the standard blockwise decode, ReTrace draws a
token from the model and checks whether its contrast has the requested sign. At carrier
positions it may draw again from the unchanged conditional, up to a budget $R$; after
exhaustion it commits one unconditional draw. A key-free plausibility floor rejects guided
proposals whose probability is too small relative to the most likely token. The resulting
procedure is rejection sampling: it changes token probabilities, but every emitted token
is an actual model proposal and retries require no additional model evaluation.

\centering
\includegraphics[width=\linewidth]{figures/fig_retrace_pipeline.pdf}
\caption{\textbf{Overall ReTrace pipeline.} \textbf{(1)} The reference DLM retains its
native block and confidence schedule. \textbf{(2)} The Reproducible Response Bank (RRB)
records keyed context-ablation responses, and the Balanced Carrier Gate (BCG) selects
positions with substantial probability mass on both signs. \textbf{(3)} At those
carriers, the Response-Aligned Resampler (RAR) accepts a plausible proposal with the
requested sign, retrying from the unchanged live conditional at most $R$ times before an
unconditional fallback. \textbf{(4)} Given the final text, model, and key, the
Response-Replay Verifier (RRV) reconstructs the RRB and applies an exact binomial test.}
\label{fig:pipeline}
\end{figure}

Figure~\ref{fig:pipeline} follows a block from the reference decoder through response-bank
construction, carrier gating, embedding, and verification. The main contributions are:
\begin{itemize}[leftmargin=1.3em,itemsep=2pt,topsep=3pt]
    \item a verifier that derives evidence from a DLM's response to keyed context
    ablations, rather than from a key--token statistic alone;
    \item a reproducible carrier construction and a finite-sample exact binomial test
    under the ideal-PRF model;
    \item a response-guided resampling embedder with an explicit retry--quality trade-off;
    and
    \item an evaluation that reports detection, matched-control perplexity, generation
    and verification cost, and post-editing failure modes on LLaDA-8B-Instruct.
\end{itemize}

At 512 tokens, the strongest evaluated ReTrace settings reach $0.70$--$0.80$ TPR at
$1\%$ FPR with measured perplexity ratios of $0.87\times$--$0.74\times$. These ratios
partly reflect the plausibility floor's preference for high-probability tokens and should
not be read as evidence that watermarking improves semantic quality. ReTrace also requires
144 masked sequence evaluations for verification and is substantially less robust to
editing than token-based baselines. We present these costs as part of the method's operating
point, not as secondary caveats.
