\section{Introduction}
\label{sec:intro}

Language-model watermarks usually encode a keyed pattern in token identities: red--green
methods bias keyed vocabulary subsets~\citep{kirchenbauer2023watermark}, sampling-based
methods couple choices to pseudorandomness~\citep{kuditipudi2024distortionfree}, and recent
diffusion language model (DLM) methods exploit unresolved context or denoising order
\citep{hong2026dgmark}. Their detectors inspect the text and key without rerunning the
generator. We instead ask whether the model itself can be the verification instrument.

A masked DLM can revisit a completed text: hide selected context and observe how the
likelihood of an emitted token changes. ReTrace compares two replayable context ablations,
giving each candidate token a signed response. A secret orientation specifies which sign
counts as a match. Under a key-independent text, orientations are independent fair bits;
the match count therefore has an exact conditional $\mathrm{Binomial}(n,\tfrac12)$ null,
without a calibration corpus or Gaussian approximation.

The embedding opportunity is \emph{local conditional ambiguity}. Several plausible tokens
may coexist at a masked position yet react with opposite signs to the two ablations
(Figure~\ref{fig:motivation}). If both signs carry probability mass, bounded resampling can
prefer the requested sign while accepting only model proposals. Small per-position biases
then accumulate in the detector. A sharp or one-sided conditional offers no choice and is
skipped rather than forced.

ReTrace comprises four modules (Figure~\ref{fig:pipeline}): the RRB, BCG, RAR, and RRV.
The RAR uses an unconditional fallback after $R$ failed guided proposals and a key-free
plausibility floor that excludes proposals far below the live argmax. This is rejection
sampling: it changes the output distribution, although retries reuse one probability row
and every committed token is drawn from the model.

ReTrace is not intended to dominate earlier watermarks on every axis. Its advantage is a
different operating constraint. Applying a prefix-based watermark to a DLM can require
strict left-to-right decoding, while order-guided methods deliberately change which mask is
resolved next. ReTrace preserves the model's native block and confidence schedule and
changes only the sampled proposal at admitted positions. More importantly, its detector
tests a keyed relation between the final text and a particular model's contextual response,
rather than a key--token hash alone. The result is checkpoint-bound and expensive, but it
provides exact conditional false-positive control even though carriers are selected from
the observed text and model predictions.

Our contributions are: (i) model-response verification with reproducible carriers and an
exact finite-sample null; (ii) a response-guided embedder with an explicit
detection--quality--compute trade-off; and (iii) an evaluation on LLaDA-8B-Instruct that
reports matched-control perplexity, model-evaluation cost, detector checks, and
post-editing failure modes. At 512 tokens, the strongest evaluated settings reach
$0.70$--$0.80$ TPR at $1\%$ FPR with measured PPL ratios of $0.87\times$--$0.74\times$,
but require 144 masked evaluations for verification and are fragile to editing. ReTrace is
therefore evidence that a model-response channel exists, not a state-of-the-art detector.
